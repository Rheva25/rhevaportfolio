Procurement & Technical Questions

Frequently Asked Questions

What exactly is delivered upon purchasing a commercial license?

You receive the complete, readable Next.js 14 and TypeScript codebase, database seed and schema migration scripts, a ready-to-run Dockerfile configuration, comprehensive architecture documentation, and 12 months of critical patch releases.

Can our internal IT team modify and extend the application?

Yes. You have full code ownership of your deployed instance. There are zero obfuscated binaries, proprietary compile steps, or phone-home telemetry locks. Your developers can tailor fields and approval steps directly.

Does SIMPEG Core require an active internet connection?

No. It can run in air-gapped institutional intranet topologies with a localized PostgreSQL database or within private institutional cloud instances behind strict VPN perimeters.

How are data migrations handled from legacy spreadsheets?

The software ships with an automated CLI utility that parses, normalizes, and ingests standard Excel and CSV personnel records into structured collections with instant schema validation reports.

Is technical onboarding or staff training included?

The single campus license includes complete written administrative guides and architectural schematics. Bespoke staff training workshops or assisted data migration can be scheduled as part of a custom deployment contract.

How does licensing work for state polytechnics with procurement rules?

We regularly accommodate formal institutional procurement processes, including official commercial invoices, tax documentation (Faktur Pajak via authorized entity), and formal software delivery sign-offs.
