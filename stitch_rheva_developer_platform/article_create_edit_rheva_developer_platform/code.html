1. Institutional Problem: Zero Satellite Connectivity in Dispersed Campuses

During peak civil servant intake examinations across East Java’s remote municipal training complexes, reliable uplink bandwidth dropped below 14 kbps for hours at a stretch. Standard enterprise architectures relying on low-latency cloud verification collapsed immediately: applicants were delayed at checkpoint turnstiles, batch attestations timeouted, and localized packet loss caused catastrophic cache invalidations.

To solve this, our design decoupled document verification from immediate persistence. Using an IndexedDB persistent client staging queue coupled with deterministic WebCrypto SHA-256 signatures, civil registry field laptops could operate indefinitely in total physical isolation.

Important Security Invariant

Local client mutation signatures must be cryptographically signed against the regional government Hardware Security Module (HSM) public keys before being accepted into the sync staging ring. Any reconciliation failure triggers an isolated quarantine queue rather than an automated transaction rollback.

TypeScript 5.4 
export async function signAndQueueDossierMutation(
  dossierPayload: CivilServiceDossier,
  privateKey: CryptoKey
): Promise<SignedMutationRecord> {
  // 1. Compute deterministic SHA-256 fingerprint
  const encoder = new TextEncoder();
  const canonicalData = encoder.encode(JSON.stringify(dossierPayload));
  const hashBuffer = await crypto.subtle.digest("SHA-256", canonicalData);
  
  // 2. Assemble immutable transaction receipt
  const receipt: SignedMutationRecord = {
    id: crypto.randomUUID(),
    fingerprint: Array.from(new Uint8Array(hashBuffer))
      .map(b => b.toString(16).padStart(2, "0")).join(""),
    timestamp: Date.now(),
    syncState: "QUEUED_OFFLINE"
  };

  await localStore.transaction("mutations", "readwrite").put(receipt);
  return receipt;
}

2. Zero-Drop Cloud Reconciliation Protocol

When hardware field laptops detect an authenticated edge relay ping, background web workers dispatch signed mutation buffers in idempotently chunked tuples. If a connection abruptly drops mid-stream, Firestore’s document-level preconditions ensure incomplete payloads abort cleanly without partial ledger corruption.
