01 // Architectural Context

Project Overview

hub

What It Is

A comprehensive, multi-campus personnel record and career advancement system developed explicitly for public vocational polytechnics. It consolidates faculty profiles, promotion credits (Angka Kredit), and government regulatory certifications into an atomic, real-time repository.

badge

Who It Serves

Built for institutional directors, campus HR registrars, state inspectors, and over 1,200 active higher education faculty members requiring transparent tracking of tenure milestones, payroll verification tiers, and state civil service documentation.

speed

What It Solves

Eradicates manual paper binder audits, isolated desktop spreadsheets, and administrative data drift that historically produced severe 3-to-6 month backlogs in payroll adjustments, grade promotions, and national accreditation compliance.

02 // The Legacy Bottleneck

Institutional Friction Across 14 Campuses

Prior to the implementation of SIMPEG Core, personnel management operated across fragmented, un-versioned Excel spreadsheets maintained independently by local campus administrators.

warning Audit Failure Scenario

When a lecturer transferred between departments, physical binders routinely went missing, triggering salary recalculation holds and blocking state research grant clearances.

1. Unsynchronous Dossier Versioning CRITICAL RISK

Multiple versions of degree credentials and decree letters (SK) were circulating simultaneously. Verification officers routinely acted upon outdated paperwork, resulting in erroneous civil service grade adjustments.

2. Manual Mathematical Compilation HIGH ERROR RATE

Academic credit calculation (Angka Kredit) followed multi-tier ministerial formulas that staff hand-tallied. Rounding inconsistencies and differing interpretation between campuses caused 40% of national submissions to be rejected.

3. Complete Absence of Immutable Audit Trails COMPLIANCE DEFICIT

No central system existed to verify which operator updated an employee’s functional status, what timestamp the change occurred, or whether supervisor authorization was actually attained.

03 // Architecture & Data Pipeline

Decoupled Server Actions & Atomic Firestore Transactions

SIMPEG Core was engineered around an immutable transactional architecture, isolating client document submission from privileged ledger persistence through strictly vetted Next.js 14 Server Actions and Firestore Security Rules.

04 // Functional Capabilities

Production Feature Architecture

PIPELINE 01 verified

Automated Dossier Verification Pipeline

Multi-stage institutional approval workflow with automatic digital watermark stamping, real-time PDF extraction via Cloud Functions, and cryptographic SHA-256 integrity checks preventing retrospective tampering of validated paperwork.

  • Automatic forensic stamp with operator identity and UTC timestamp.
  • Direct PDF page visual comparison engine with legacy dossier records.
ENGINE 02 calculate

Atomic Tenure & PAK Point Calculation Engine

Deterministically calculates credit points (Angka Kredit) according to strict National Educational Ministry standards. Evaluates teaching, research publications, community service, and administrative service without floating point rounding divergence.

  • Fixed-point decimal math library preventing currency and point discrepancies.
  • Automated milestone notifications 6 months prior to rank eligibility window.
SECURITY 03 admin_panel_settings

Decentralized Campus RBAC with Regional Oversight

Strict isolation of administrative boundaries. Individual campus registrars can only query and mutate records within their accredited jurisdiction, while the Regional Directorate possesses comprehensive cross-campus read-only compliance telemetry.

  • Zero data leakage between participating vocational campuses.
  • Real-time audit log streaming to prevent unauthorized administrative elevation.
STORAGE 04 cloud_sync

Resilient Chunked Document Ingestion

A resilient upload subsystem tailored for faculty operating on low-bandwidth campus network links. Implements chunked multi-part uploading directly into Firebase Storage with auto-retry and byte-level checksum validation.

  • Client-side MIME type sniffing before data leaves the browser buffer.
  • Automatic image optimization and PDF thumbnail compilation in Cloud Functions.

07 // Engineering Hurdles

Critical Development Challenges Solved

CHALLENGE 01 account_tree

Deeply Divergent Campus Taxonomies

Across the 14 vocational institutions, organizational structures differed significantly: some treated specialized lab instructors as academic lecturers, while others classified them as technical personnel with alternate evaluation formulas.

Engineered Solution:

Designed a polymorphic schema architecture utilizing Zod discriminators. Each employee record stores a strict taxonomy profile key that dynamically controls the evaluation pipeline and required dossier attachments.

CHALLENGE 02 dataset

Zero-Downtime Legacy Data Migration

Over 1,200 historical personnel records resided in unindexed, inconsistently formatted spreadsheets with missing national identity numbers and ambiguous tenure dates that could not afford any system downtime during active semester payroll runs.

Engineered Solution:

Constructed an idempotent Node.js ETL migration pipeline. Implemented batch dry-run validation passes with anomalous data quarantine queues, successfully seeding 100% of historical dossiers without interrupting ongoing payroll audits.
